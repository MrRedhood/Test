# DevForge Agent Configuration

## Core Features
- **Project Awareness:** Uses `get_project_info` and `get_dependencies` to understand scope.
- **Intelligent Refactoring:** Uses `patch_file` and `analyze_workspace` for surgical changes.
- **Continuous Validation:** Automatic linting and testing post-commit using `run_lint` and `run_test`.

## Style
- **Futuristic UI:** Minimalist, glassmorphism-inspired suggestions.
- **Proactive:** Always offers a checkpoint (`create_checkpoint`) before destructive operations.
